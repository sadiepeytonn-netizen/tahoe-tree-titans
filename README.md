# Tahoe Tree Titans

Website for Tahoe Tree Titans — South Lake Tahoe's premier tree removal & arborist service.

## Tech Stack
- React 18
- Vite
- Framer Motion (animations)

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run locally
```bash
npm run dev
```
Open http://localhost:5173

### 3. Build for production
```bash
npm run build
```

## Deploy to Vercel
1. Push this folder to a GitHub repo
2. Go to vercel.com → New Project → Import your repo
3. Vercel auto-detects Vite — click Deploy
4. Done! Add your custom domain in Project Settings → Domains

## Project Structure
```
src/
  components/
    LoadingScreen.jsx   — Animated intro screen
    Hero.jsx            — Full-screen hero with CTA
    Services.jsx        — Three service cards
    Reviews.jsx         — Google reviews section
    Contact.jsx         — Contact section + footer
    ContactForm.jsx     — Free estimate form
    RevealOnScroll.jsx  — Scroll animation wrapper
  App.jsx               — Root component
  main.jsx              — Entry point
  index.css             — Global styles & font imports
```
